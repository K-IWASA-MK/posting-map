# MIE03 シート生成ルール定義（SSOT）

## 1. 入力データ
* **SSOT**: `MIE03_ADDRESS_MASTER.csv`
* **対象件数**: 858件（固定）

## 2. 自治体グループ順
* **参照**: `MIE03_MUNICIPALITY_ORDER.csv`
* **順序 (`priority,city_name`)**:
  1. 四日市市
  2. 桑名市
  3. いなべ市
  4. 桑名郡木曽岬町
  5. 員弁郡東員町
  6. 三重郡菰野町
  7. 三重郡朝日町
  8. 三重郡川越町

## 3. 自治体内ソート
* **同一自治体内**: 郵便番号数値昇順
* **例 (四日市市)**:
  - 510-0001
  - 510-0002
  - 510-0003

## 4. シート分割ルール
* **1シート**: 10件固定
* **例 (四日市市)**:
  - 四日市市
  - 四日市市(2)
  - 四日市市(3)
  - ...
  - 四日市市(35)

## 5. シート命名規則
* **自治体名 + 連番**
* **ルール**: 10件以内の1枚目であっても `(1)` 表記はなし。2枚目以降に `(2)`, `(3)`... を付与。
* **例 (10件以上)**:
  - 四日市市
  - 四日市市(2)
  - 四日市市(3)
  - 最後: 四日市市(35)

## 6. 自治体境界ルール
* **禁止事項**: 同一シート内に「四日市市」と「桑名市」など複数自治体のデータが混在することを禁止。
* **分離徹底**: 自治体単位で必ず独立したシートに分離する。

## 7. タブ並び順ルール
* **物理タブ順**: `MIE03_MUNICIPALITY_ORDER.csv` の `priority` 順
* **例**:
  - 四日市市 ➔ 四日市市(2) ➔ ... ➔ 四日市市(35)
  - 桑名市 ➔ 桑名市(2) ...
  - いなべ市
  - 桑名郡木曽岬町
  - 員弁郡東員町
  - 三重郡菰野町
  - 三重郡朝日町
  - 三重郡川越町

## 8. 禁止事項 (Code level)
* 自治体順のコード内ハードコード
* 市町村名補正・文字切り出しロジック
* `includes` / 正規表現による部分一致判定
* 郡名削除・置換処理
* 自動推測処理
* 郵便番号だけで全体の自治体境界を無視してソートする処理

## 9. SSOT 構造
```
MIE03_MUNICIPALITY_ORDER.csv
        │
        ▼ (自治体順)
MIE03_ADDRESS_MASTER.csv
        │
        ▼ (住所データ)
   生成ルール (v2_batch.js)
        │
        ▼
   エリアシート
```
