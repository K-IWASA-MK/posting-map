# 01_MASTER/Archive

## 役割
Rule-001 (MASTER昇格ルール) に基づき、過去の MASTER スプレッドシートおよびマニフェスト（v1, v2 ...）を履歴アーカイブとして管理・保管する領域。

## アーカイブ保存規則
1. MASTER が新しいバージョンへ昇格する際、旧 MASTER のマニフェスト・スプレッドシート参照を本フォルダ配下にバージョン単位（例: `MASTER_v1/`, `MASTER_v2/`）で保存する。
2. 旧 MASTER ファイルおよび定義は絶対に削除・破棄しない。
3. 全アーカイブは Google Drive (`1FfcVEQjod--rZSucOPFJD2DJ58hV650_`) 上の `01_MASTER/Archive/` フォルダへも完全同期保存される。
