## 役割
POSTING MAP および AIOS 全体における標準運用手順書（SOP）、マニュアル、AI社員教育資産を管理する領域。

---

# ■ AI社員教育ガバナンス (AI Workforce Governance Rules)

### 核心思想
> **「人間が初めて行う作業 = AI社員の教育機会」**
> **「AI社員は『設計書から学ぶ』のではなく、『成功した経験から学ぶ』。」**

---

### Rule-AI-001 : SOP化ルール
人間が新しい運用手順を確立した場合、その手順は必ず AI社員の SOP として教育・文書化し、自動化プログラムおよびマニフェストへ昇格させる。

### Rule-AI-002 : 一度覚えた作業はAI社員へ移管
同じ作業を二度、人間が行わない。一度確立・検証された作業は次回からすべて AI社員へ移管・任せる。

### Rule-AI-003 : SOPはプラットフォーム資産
SOP は単一プロジェクトの一次メモではなく、以下の共通プラットフォーム資産として一元管理する：
1. **AI社員の自律ワークフロー** (`/AI社員/[Agent名]/`)
2. **公式運用マニュアル** (`FIELD_OPERATIONS_PLATFORM/07_MANUAL/`)
3. **品質管理・監査基準** (`Master Governance Rules`)

### Rule-AI-004 : 実証済み経験限定原則 (Proven Experience Only Principle)
* **「SOPは完成した経験から作る。予測や設計から作ってはならない。」**
* ❌ 予想SOP / ❌ 設計SOP / ❌ 仮説SOP で AI社員を教育することを厳禁とする。
* ✅ 実証済みSOP / ✅ 運用済みSOP / ✅ 承認済みSOP のみを AI教育資産としてマニュアル化・組み込みを行う。
* *(例: 地区データ投入SOP は、まず三重第3区のデータ入力が完全に完成・検証された後に初めて作成する)*
