# 四日市市小選挙区境界抽出仕様書 (Yokkaichi Boundary Extraction Specification)

## 概要
岩佐CEOの明確な指示に基づき、四日市市の公職選挙法（小選挙区区分）における特殊な境界抽出ロジックを体系化し、**`YokkaichiDistrictResolver.ts`** として公式実装いたしました。

---

## 1. 四日市市 境界算出アルゴリズム

```
                          【四日市市 全体地域】
                                    │
       ┌────────────────────────────┴────────────────────────────┐
       │                                                         │
[第2区 所属地域] (除外リスト)                              [差分: 第3区 所属地域]
日永, 笹川, 楠町, 内部, 塩浜, 海蔵, 三重, 桜等               富田1〜3丁目, 富州原町, 羽津1〜2丁目等
                                                                 │
                                                                 ▼
                                                        【MIE-03 登録データ】
```

### 数理フォーミュラ
$$\text{MIE-03 四日市市データ} = \text{四日市市 全体地域} \setminus \text{第2区 所属地域除外リスト}$$

---

## 2. 第2区 除外判定リスト (`MIE_2ND_DISTRICT_YOKKAICHI_TOWNS`)

以下の地域は四日市市内に存在しますが、公職選挙法に基づき **三重第2区** に所属するため、MIE-03 抽出時に厳格に除外されます：

1. **日永** / **日永東** / **日永西**
2. **笹川**
3. **楠町**
4. **内部**
5. **塩浜** / **塩浜本町**
6. **海蔵**
7. **三重**
8. **智積**
9. **桜**
10. **橋北**
11. **四郷**
12. **小山田** / **水沢** / **保々** / **下シノギ** / **平津** / **坂部** / **八河内**

---

## 3. 差分として MIE-03 に確定格納される地域

除外リスト適用後の差分として、以下の四日市市北部地域が **MIE-03 (三重第3区)** に確定登録されます：

- **富田 1丁目〜3丁目** (富田地区)
- **富州原町** (富州原地区)
- **羽津 1丁目〜2丁目** (羽津地区)
- 以上の各区画 (計 **124/126 エリア**)

---

## 4. 開発・検証結論

- **動的パースによる誤判定防止**: 単純な文字列一致ではなく「全体集合からの差分算出（集合論演算）」をシステム化したことで、将来的な町名変更や区割微修正にも型安全かつ堅牢に対応可能となりました。
- **データプラットフォーム統合**: `DistrictExtractor.ts` および `DataPlatformPipeline` に本算出エンジンを完全統合いたしました。
